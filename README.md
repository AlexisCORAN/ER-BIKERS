# ER BIKERS — Responsive E-Commerce Web Platform

Landing page and digital product catalog built from scratch for **ER Bikers**, an e-commerce brand specializing in motorcycle riding gear and protective accessories (tactical gloves, balaclavas, neck gaiters, and shoe protectors).

## 🚀 Project Overview

This project focuses on building a fast, clean, and fully responsive frontend storefront without heavy external frameworks, prioritizing semantic structure, visual hierarchy, and cross-device compatibility.

### Key Features
* **100% Responsive Design:** Fluid layouts adapted for mobile, tablet, and desktop viewports using CSS Flexbox, CSS Grid, and custom media queries.
* **Semantic HTML5 Architecture:** Clean document outline using proper heading hierarchy (`h1`–`h3`), accessible navigation, and structured product cards.
* **Modern CSS3 Styling:** Custom animations, hover transitions, consistent color palette, and modular stylesheet organization.
* **On-Page SEO & Asset Optimization:** Optimized product imagery for fast load times, descriptive `ALT` attributes, and structured meta tags.
* **Interactive UI (In Progress):** Implementing vanilla JavaScript (ES6+) for dynamic product filtering, interactive modals, and client-side cart state management.

## 🛠️ Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3 (Flexbox, Grid, Keyframe Animations, Media Queries)
* **Scripting:** JavaScript (ES6+) *(Active development)*
* **Tools:** Git, GitHub, VS Code
